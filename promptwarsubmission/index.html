UNDER THE HOOD

Small by design. Private by default.

Browser-first architecture

Plain HTML, CSS and JavaScript load local sample files. Leaflet draws an OpenStreetMap view; Google Maps opens only when you choose directions.

Safety-aware suggestions

Scores are illustrative signals, never guarantees. The planner skips places with quality alerts by default and avoids lower-safety stops in evening slots.

Privacy choices

No account or contact data. Preferences and itinerary use localStorage. Feedback and attachments use IndexedDB only on this device.

Input safety

Feedback is rendered with text nodes, not raw HTML. Media capture asks the browser for camera or microphone access and has time and file-size limits.
