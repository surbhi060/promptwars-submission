## Problem

CityExplorer asks for a smart, practical way to explore a city while weighing discovery, culture, safety, transport, affordability and local feedback.

## Solution

PuneMitra is a mobile-friendly personal Pune guide for locals, newcomers and visitors. It turns local sample place data into preference-led discovery, comparisons, transport guidance, a safety-aware itinerary, a multilingual phrasebook and private feedback.

## Features

- Preference onboarding with adaptive nature, heritage and food/shopping themes
- 35 sample places, quality warnings, score rationale and approximate nearby transport
- Leaflet + OpenStreetMap map, Google Maps directions and lost-mode emergency guidance
- Two- to three-place comparison
- Deep daily planner with meals, travel gaps, stay suggestions, swap/remove controls and print support
- 25-phrase, 10-language phrasebook using device speech synthesis
- Device-only feedback with keyword tags, photo compression, optional voice/video capture and map pins
- Under-the-Hood security and privacy explanation

## Technology

Plain HTML, CSS and JavaScript; Leaflet and OpenStreetMap loaded from cdnjs. Preferences and plans stay in browser localStorage. Feedback and optional media stay in browser IndexedDB.

## Important demo note

All locations, opinions, prices, warnings, scores, recommendations, routes and feedback are **demo data**. Verify before you travel. This project has no server, no account system, no API keys and no shared reporting database.
